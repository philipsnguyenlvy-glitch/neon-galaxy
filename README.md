# 🚀 Neon Galaxy - Space Shooter

A retro-arcade HTML5 space shooter game built with Canvas and Web Audio API.

![Neon Galaxy](https://img.shields.io/badge/Made%20With-HTML5%20%7C%20CSS3%20%7C%20JavaScript-00f0ff?style=for-the-badge)

## 🎮 Features
- **Neon Synthwave Aesthetics**: Parallax starfield, glowing neon lasers, particle explosions, and screen shake.
- **Weapon System**: 5 upgradable weapon tiers (Single beam, Dual laser, Spread shotgun, Quad cannon, Overdrive barrage).
- **Power-ups**:
  - `[P]` Weapon level upgrade
  - `[S]` Shield / HP restore
  - `[B]` Screen-clearing Smart Bomb
  - `[★]` Bonus Score
- **Enemies & Bosses**: Asteroids that fracture into smaller rocks, agile Drone Scouts, armored Heavy Cruisers, and giant Mothership Bosses with spiral bullet patterns.
- **Pure Web Audio API**: Procedural sound effects synthesized on the fly (no external audio assets required).
- **Cross-Platform**: Playable with Mouse, Keyboard (WASD / Arrows), or Touch controls.

## 🕹️ Controls
- **Move**: `W`, `A`, `S`, `D` / Arrow Keys / Mouse cursor / Touch drag
- **Shoot**: `Spacebar` / Left Click (hold to auto-fire)
- **Bomb**: `E` / Right Click
- **Pause**: `P`

## 🚀 How to Run
Simply open `index.html` in any modern web browser or deploy to GitHub Pages!
